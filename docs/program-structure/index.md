# Program Structure

A practical learning journey that moves from **business scoping**, through **data analysis and modelling**, into **production-ready delivery and communication**. Each module builds on the skills developed earlier in the journey and applies them to a shared capstone use case.

## Learning Journey at a Glance

The full Learning Journey will take place across 6 months. Each module corresponds roughly to one month each.

Each module will be made up of different types of session:

- **Classroom**: In-person classroom sessions taught by an Xebia instructor
- **Study**: Online drop-in study sessions where groups can work on their capstone projects together. The trainer will be available for calls/messages during these hours
- **Hackathon** (module dependent): A hackathon day where trainees will apply the skills corresponding to the [Learning Objectives](./learning-objectives.md) for that module.
